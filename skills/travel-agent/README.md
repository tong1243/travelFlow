# 旅游助手 Agent 技能包

这个目录提供可直接接入大模型函数调用（Tool Calling）的旅游助手技能包。

## 文件说明

- `system_prompt.md`：旅游规划 Agent 系统提示词
- `tools.json`：14 个技能函数定义（JSON Schema）

## 使用方式

1. 将 `system_prompt.md` 作为系统提示词传给模型。
2. 将 `tools.json` 作为可用工具列表传给模型。
3. 模型发起工具调用后，由业务层执行真实查询。
4. 将工具执行结果回传给模型，继续完成最终回答。

## 设计原则

- 优先调用工具获取真实信息，不编造事实。
- 支持多轮对话中的用户偏好记忆。
- 生成行程强调可执行、节奏舒适、路径合理。
- 输出简洁、结构清晰、便于直接使用。
