# 用户偏好档案（可直接上传到“我的偏好”）

## 基础信息
- 用户昵称：示例用户A
- 常用出发地：上海
- 常见出行人数：2人
- 同行类型：朋友 / 情侣

## 时间与节奏偏好
- 单次出行天数偏好：3-5天
- 每日出发时间：不早于 09:00
- 行程节奏：每天不超过 3 个核心点位
- 不接受“高强度打卡”，更偏向慢游

## 交通偏好
- 城际优先：高铁 > 飞机 > 大巴
- 市内优先：地铁 / 步行 / 网约车
- 不喜欢：凌晨航班、频繁换乘
- 可接受单段通勤时长：60分钟以内

## 住宿偏好
- 酒店预算：300-500 元/晚
- 位置偏好：地铁站步行 800 米以内
- 房型偏好：大床房，安静楼层
- 必要条件：独立卫浴、空调、免费 Wi-Fi
- 加分项：可免费取消、含早餐

## 餐饮偏好
- 口味偏好：清淡、微辣
- 忌口：香菜、花生过敏
- 用餐策略：中午简餐，晚上体验当地特色
- 人均餐饮预算：80-150 元/天

## 景点与活动偏好
- 喜欢：自然风景、城市漫步、博物馆、夜景
- 一般：网红打卡点
- 不喜欢：排队超过 40 分钟的热门项目
- 拍照需求：每天安排 1 个高质量拍照点

## 预算偏好
- 人均总预算区间：2000-3500 元（3-4天）
- 预算分配建议：
  - 交通：35%
  - 住宿：35%
  - 餐饮：20%
  - 机动应急：10%

## 风险与备选规则
- 遇到雨天：优先切换室内路线（博物馆/展馆/商圈）
- 遇到大客流：改走次热门景点或错峰至傍晚
- 预算超支预警：预计超支 15% 以上时，降低住宿档位或减少付费项目
- 交通延误：优先保留当日一个核心景点，其余顺延

## 输出偏好（给智能体）
- 输出语言：中文
- 输出格式：
  1. 每天按“上午/下午/晚上”给安排
  2. 每天给预算小计
  3. 明确写出“可替换方案”
  4. 标注步行/通勤时长
- 结果风格：简洁、可直接执行，少空话
